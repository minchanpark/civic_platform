# CivicPin 개발 완료 기준

기준 문서: `docs/civic-pin/PRD.md` Approved 2.0

## 목표

개발 완료는 PRD의 핵심 여정 J-01~J-06이 정적 데모가 아닌 로컬 Supabase의 실제 DB, Auth, Storage, Realtime, Mailpit 데이터로 연결되고 아래 수용 기준과 품질 게이트를 모두 통과한 상태다.

법률 검토, 실제 운영 SMTP·AI 사업자, 운영 백업 인프라, iOS/Android 실기기와 정식 스크린리더 검증은 개발 완료와 분리한 파일럿 출시 승인 게이트다. 애플리케이션은 이 검증을 수행할 수 있는 코드와 운영 절차를 제공해야 하지만 외부 승인 자체를 개발 완료로 가장하지 않는다.

## 품질 게이트

```bash
npm test
npm run typecheck
npm run lint
npm run build
npm run test:db
npm run lint:db
npm run test:e2e
```

기능을 완료로 바꾸려면 해당 PRD 요구사항의 정상 경로, 권한 거부 경로와 중요한 실패 경로가 실행 가능한 테스트로 남아 있어야 한다. 최종 완료 전에는 Ponytail diff 리뷰로 불필요한 코드와 의존성이 없는지 확인한다.

## 개발 루프

1. 가장 위험한 미완료 수용 기준 하나를 선택한다.
2. 관련 PRD 요구사항과 현재 UI→API→DB→Storage/외부 의존 경로를 끝까지 읽는다.
3. 실패하는 최소 테스트 또는 계약을 먼저 추가한다.
4. 기존 코드와 플랫폼 기능을 우선 사용해 가장 작은 수직 변경을 구현한다.
5. 관련 테스트와 전체 품질 게이트를 실행하고 이 표의 상태·증거를 갱신한다.
6. 모든 항목이 완료될 때까지 반복한다.

## 현재 기준선 (2026-08-16)

- 통과: 단위 테스트 23개, Playwright 8개, 타입 검사, 애플리케이션 lint, production build, DB 계약 153개, DB lint
- 연결됨: 8개 시민 신고 카테고리·13개 공식 행정구 경계, 접수 이메일 OTP·티켓 조회 매직 링크, 비공개 사진 업로드·재인코딩, 티켓 제출·소유자 조회, 관리자 5상태 처리, 현장상태·재발·문제지점, 완료 이메일 outbox, 익명 90일 snapshot/player
- 디자인: 루트 `DESIGN.md`에 `/` 시민 Service Portal과 `/admin` 관리자 KRDS를 경로별 계약으로 확정했다. 행정구 지도 이동·현재 위치·사진 선택/촬영과 320/390/1440px, 관리자 150% 글자 확대·선명한 화면, 폼 오류 요약, dialog 포커스 trap/복귀를 실제 Chromium에서 검증했다.
- 관리자 보안: 비노출 OTP 응답, 계정·IP durable 잠금, bcrypt 직원번호와 auth session별 12시간 이하 grant를 DB와 실제 브라우저에서 검증했다.
- AI 지원: 제목·본문·카테고리만 전달하는 bounded provider 계약, 미설정·실패 시 원자적 `평가 필요`, 원본 AI 결과 불변, 관리자 사유·멱등 변경, 저장·재시도되는 요약/답변 초안과 사람의 최종 검토 경계를 검증했다.
- 현장 해결: 관리자 처리 후 비공개 사진·점검 이력, 시민 본인 완료·현장 미해결 원본 티켓과 현재 위치의 500m 서버 검증 후에만 열리는 앱 카메라, 5분·1회 토큰, 일반 사진 승인 차단, 24시간 중복 제외와 시급 문제지점 임계치를 검증했다.
- 관리자 운영: 현재 viewport만 읽는 지도, 상태·카테고리·행정구·위험도·문제지점·재발 공통 필터, 5건 문제지점과 시급 문제지점 강조, 서버 페이지네이션·정렬, 모든 상세 열람 감사와 공개 지표 제외 이력을 검증했다.
- 복구: Bearer로 보호된 자동 작업, 이메일·AI backoff, 5분 집계 snapshot, orphan 사진 정리, 실제 데이터가 든 DB·비공개 Storage 백업과 격리 복원을 검증했다.
- 남은 항목은 개발 미완료가 아니라 파일럿 출시 승인 게이트다: 운영 SMTP·AI·CAPTCHA·백업 인프라, 실기기/스크린리더와 대만 법률·정책 승인.
